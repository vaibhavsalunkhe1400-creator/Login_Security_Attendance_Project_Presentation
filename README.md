# Login Security & Attendance Management System

## 📌 Project Overview
This project is developed using Python. It provides a basic login security system that verifies user credentials and records attendance information after successful login.

## 🚀 Features
- User Login Authentication
- Username and Password Verification
- Login Success and Failure Messages
- Automatic Attendance Recording
- File Handling using Python
- Attendance Records Stored in a `.log` File

## 🛠️ Technologies Used
- Python
- VS Code
- File Handling
- Conditional Statements (`if-else`)

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project in VS Code.
3. Run the Python file:
   ```bash
   python main.py
   ```
4. Enter your username and password.
5. After successful login, attendance details are saved in the log file.
